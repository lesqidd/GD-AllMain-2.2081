# GD All Main Completer

A Geode mod for Geometry Dash 2.2081 that lets you complete all the main levels instantly.

### Features
- Completes all 22 classic main levels
- Sets normal mode to 100%
- Sets practice mode to 100%
- Unlocks all 66 secret coins
- Updates your local level stats
- One-click completion button

### How to use
1. Build the mod using GitHub Actions
2. Download the `.geode` file
3. Put it in your `Geometry Dash/geode/mods` folder
4. Launch Geometry Dash
5. Click **Main 100%** and confirm

### Info
Made for GD 2.2081 on Windows.
